Foot-Track Extractor

Extracts a per-foot position track from a recorded clip — MediaPipe Pose in the browser (X lateral, Y lift), plus optional Depth Anything V3 for Z (front/back). Output is a *.foottrack.json you load into the warehouse demo alongside the recording + video: it drives the 3D stance and real step length / sway on the footstep map.

Notes: X/Y come from Pose (hip-relative, so camera pan doesn't shift both feet); the ground baseline is the lowest ankle across the clip. Z is Pose world-depth unless the Depth Anything server is on. Depth Anything returns a colormapped depth JPEG + closestDepth; per-foot Z here samples that map's luminance as a relative proxy — for metric Z, extend the server to return raw depth at requested points, and add a floor calibration. Occluded feet drop to confidence 0 (the demo falls back to the insole estimate).
